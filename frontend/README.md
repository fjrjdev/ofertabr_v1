# Frontend - Next.js

Este diretório irá conter o frontend em Next.js do OfertaBR.

## Próximos Passos

1. Inicializar projeto Next.js com TypeScript
2. Configurar integração com a API backend
3. Implementar autenticação passwordless
4. Desenvolver interface de gerenciamento

## Estrutura Planejada

```
frontend/
├── src/
│   ├── app/              # App Router (Next.js 13+)
│   ├── components/       # Componentes React
│   ├── lib/              # Utilitários
│   └── hooks/            # Custom hooks
├── public/               # Arquivos estáticos
├── package.json
└── next.config.js
```

## Como Iniciar (em breve)

```bash
cd frontend
npm install
npm run dev
```
